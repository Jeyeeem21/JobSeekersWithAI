AUTOMATIC DEPLOYMENTS (CONTINUOUS DEPLOYMENT)

✨ GOOD NEWS: Once deployed, Vercel automatically deploys on every push!

HOW IT WORKS:
1. You make changes to your code
2. Commit and push to GitHub:
   git add .
   git commit -m "Your changes"
   git push origin main

3. Vercel automatically detects the push
4. Builds and deploys your app
5. You get a new URL for preview
6. Production updates automatically!

You'll receive:
- Email notifications
- Deployment status on Vercel Dashboard

────────────────────────────────────────────────────────────────────────────────
TROUBLESHOOTING COMMON ISSUES
────────────────────────────────────────────────────────────────────────────────

ISSUE 1: BUILD FAILS
────────────────────────────────────────────────────────────────────────────────
ERROR: "Build failed"

SOLUTION:
1. Check build logs on Vercel dashboard
2. Verify package.json scripts:
   "scripts": {
     "build": "vite build"
   }
3. Make sure all dependencies are in package.json
4. Test build locally first: npm run build

────────────────────────────────────────────────────────────────────────────────
ISSUE 2: 404 ON REFRESH
────────────────────────────────────────────────────────────────────────────────
ERROR: Page shows 404 when you refresh a route

SOLUTION:
Create vercel.json in project root:

{
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}

Then commit and push:
git add vercel.json
git commit -m "Add vercel.json for SPA routing"
git push origin main

────────────────────────────────────────────────────────────────────────────────
ISSUE 3: ENVIRONMENT VARIABLES NOT WORKING
────────────────────────────────────────────────────────────────────────────────
ERROR: API calls fail or undefined variables

SOLUTION:
1. Go to Project Settings > Environment Variables
2. Add your variables with VITE_ prefix:
   VITE_API_URL = https://your-api.com
3. Redeploy the project
4. Make sure to use import.meta.env.VITE_API_URL in code

────────────────────────────────────────────────────────────────────────────────
ISSUE 4: SLOW BUILD TIMES
────────────────────────────────────────────────────────────────────────────────
SOLUTION:
1. Check if node_modules is in .gitignore (it should be)
2. Optimize package.json (remove unused dependencies)
3. Use Vercel's build cache (automatic)

────────────────────────────────────────────────────────────────────────────────
ISSUE 5: DEPLOYMENT STUCK
────────────────────────────────────────────────────────────────────────────────
SOLUTION:
1. Cancel deployment in Vercel dashboard
2. Check GitHub repo for issues
3. Try redeploying manually:
   - Click "Deployments" tab
   - Click "..." menu on latest deployment
   - Select "Redeploy"
